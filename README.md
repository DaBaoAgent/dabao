# DABAO — AutoYY 推广发布与互动

面向 AutoYY 纪录片解说项目的社交媒体发布与互动技能，覆盖多平台视频分发、发布状态追踪、评论回复和私信转化。

## 工作流

准备成片 → 多平台发布 → 获取帖子链接 → 处理评论互动 → 私信发送项目入口。

完整配置、发布参数和互动规范见 [`skills/dabao/SKILL.md`](skills/dabao/SKILL.md)。
