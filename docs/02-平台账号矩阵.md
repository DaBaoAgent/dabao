## 文案口径（踩过的坑）

- caption 只取 `description`；`title` 仅对 YouTube 生效（YT 标题）/ X 帖文（走 `title`）。
- IG / TT 的 caption **发出去改不了**（无 API 编辑）→ 发前核对 `发布文案-多平台.txt`。
- IG 评论不带链接；需要引流一律「看我主页简介」。
- X 正文不放链接（upload-post 会剥 URL），CTA 引流主页简介。
- 中文 Graph 写操作（评论/回复/DM）必须 python+requests，**不要 curl**（必 mojibake）。
