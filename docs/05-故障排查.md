- **处置**：IG Graph / TG embed / fxtwitter 全不可达 → 值班四项检查标「通道阻断未执行」，**绝不跑批量扫**（会落盘空数组假报告）。请宝哥刷新/切节点。

## 4. 直连 Graph 的代理写法

- `requests.Session()` + `trust_env=False`；代理表里**显式代理在前、`None` 在最后**（`proxies=None` 会继承 env 的 socks 并挂死 60s/次）。
- hermes venv 的 requests **没装 PySocks** → python 代理表只用 `http://127.0.0.1:15715`，别放 `socks5h://`（curl 可以用 socks5h）。
